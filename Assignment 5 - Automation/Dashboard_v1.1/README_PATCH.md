# Dashboard v1.2.0 — Priority list
Stop only port 8004. Back up app.js, index.html and style.css from Dashboard_v1.1, then replace those three files with this patch. Restart start_dashboard.bat and manually open http://127.0.0.1:8004/ (Ctrl+F5). No database or API changes. The list includes every record returned by /items, including prior synthetic regression records. P1–P4 are sorted numerically; missing/undetermined priorities appear last, never assigned P4. Within a priority, assessment timestamp then update timestamp and ID are used for display ordering; this is not a scheduler. Reviewed records are retained and review decisions shown separately. Click a scenario to inspect details. Refresh after external changes. Test list ordering, priority filtering, detail navigation, duplicate notice and refresh after submission.
