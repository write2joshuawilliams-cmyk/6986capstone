1. Shared Drive Quota Warning on Departmental Archive
Short Description: Shared drive volume approaching 90% storage capacity

Description: Automated monitoring alerted that the \\filesrv02\ops_archive volume is at 89% utilization after a batch of quarterly reporting exports was uploaded. No write errors have been reported yet.

Label: Routine Task

Reasoning: Capacity thresholds at 85%–90% with no active outage or blocked users are standard storage-maintenance work. Expanding the volume or archiving older logs follows documented capacity-management procedures without immediate service disruption.

2. Intermittent Packet Loss Between App Tier and Reporting Database
Short Description: Intermittent timeouts from reporting app tier to SQL reporting node

Description: Analysts report sporadic query timeouts when pulling daily operational dashboards between 9:00 AM and 11:00 AM. Ping and port checks show intermittent packet loss across a core switch trunk linking the application subnet and database VLAN.

Label: Escalation Required

Reasoning: Sporadic packet loss across core network infrastructure during peak morning reporting hours affects multiple users and risks cascading timeouts across dependent services. It requires escalation to senior network engineering and infrastructure leads to isolate hardware faults, duplex mismatches, or congestion.

Security / Policy

Short Description: Provision standard non-privileged user account for incoming contractor

Description: An onboarding request was submitted with approved manager sign-off and a defined end date for a new systems analyst starting Monday. The request asks for standard domain access and email only, with no elevated privileges.

Label: Routine Task

Reasoning: Creating a standard, time-bound account using a pre-approved role template and valid authorization follows standard identity and access management (IAM) workflows and does not require escalation.

7. Repeated Failed MFA Prompts Followed by Successful Off-Hours Login
Short Description: Burst of failed MFA challenges prior to unusual sign-in

Description: Identity logs show 14 rejected MFA push notifications within six minutes for a single user account, followed shortly by a successful sign-in from an unfamiliar IP range outside normal business hours.

Label: Escalation Required

Reasoning: MFA fatigue followed by an anomalous successful authentication is a strong indicator of potential credential or token compromise. It requires immediate escalation to the Security Operations Center (SOC) / Incident Response team to contain the session, revoke tokens, and investigate.

8. Temporary Exception Request to Bypass Screen-Lock Timer
Short Description: Request to extend workstation auto-lock timeout from 10 to 60 minutes

Description: A team lead requested a 60-minute screen-lock timeout on three lab workstations used during group walkthroughs, citing frequent re-authentication during demonstrations.

Label: Escalation Required

Reasoning: Weakening an endpoint security baseline (extending auto-lock beyond policy limits) introduces physical/shoulder-surfing exposure and sets a policy precedent. It should be escalated to Information Security governance/policy owners for formal risk review and exception approval.

9. Stale Service Account Password Rotation Reminder

Label: Routine Task

Reasoning: Routine credential rotation on a documented service account following a tested procedure is standard operational hygiene, provided dependent jobs are updated and verified during the maintenance window.

10. Unauthorized Local Admin Tool Detected on Managed Laptop
Short Description: Endpoint agent flagged unauthorized remote-access utility on workstation

Description: Endpoint detection software quarantined an unsigned remote-support binary placed in a user's Downloads folder on a corporate laptop. The user states a third party told them to run it to troubleshoot a display issue.

Label: Escalation Required

Reasoning: Unapproved remote-access tooling—especially when paired with social-engineering-style guidance—creates a high risk of unauthorized access or backdoor persistence. Escalating to Security/IR ensures proper host isolation, forensic check, and user guidance.
