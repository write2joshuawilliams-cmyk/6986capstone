# Development-only lexical comparator — CA-05

The instructor found that 12 of the original 27 regex rules matched test text but no Train or Validation text. Original recall was 10% Train, 10% Validation and 55% Test. Preserve that result, but do not treat the test comparison as independent evidence of superiority. The original baseline was also weak on development data.

This is a new, **retrospective** training-derived rule comparator, not the historical baseline and not a measured human/generalist baseline. Its rule learning uses only the 120 original Train cases (60 positives). Standard English stopwords are removed. Candidate unigrams occur in at least three training documents and have at least 80% training precision. Greedily add at most ten OR rules that increase training true positives while maintaining aggregate training precision of at least 80%; ties prefer fewer additional false positives, then alphabetical order. Stop if no eligible addition exists; an empty rule set predicts routine for all items. These design choices are fixed for this run, not proven optimal. The 80% here is a comparator construction constraint, not evidence that the historical precision safeguard was preregistered.

No validation or test results select the rules. Score once on Train (apparent fit), Validation, original test and independent robustness set. The latter two are previously observed datasets; this is NOT a fresh blinded test. No retraining or tuning of NB-v1. Do not select a new comparator after seeing these results; a truly independent future comparison requires a new holdout. The rule comparator may still exploit authorship artifacts. No guarantee it outperforms the old baseline.

From the repo root, using Python 3.13 with scikit-learn 1.6.1, pandas 3.1.1 and openpyxl 3.1.5, run the script with the existing API virtual environment. It verifies four input hashes and protects existing results. Outputs: run.json, comparison.csv, predictions.csv, rule_selection.csv. Confidence intervals are in run.json. The original frozen model and datasets are never written. Only scenario_text is scored; labels are used to derive rules from Train and evaluate results. The original 27-rule figures are historical, not re-estimated here.
